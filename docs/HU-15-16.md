## What was implemented

### HU-15 — Activity log

- Table `client_history` (migration `clients/.../1792720000000-CreateClientHistoryAndPortfolios.ts`): `client_id`, `user_id`, `action`, `entity_type`, `entity_id`, `description`, `metadata` (jsonb), `created_at`.
- `TypeOrmActivityLogService` (`src/shared/activity-log/infrastructure/`) replaces the old no-op adapter. The port keeps the same `record(entry)` signature, plus an optional `clientId` (otherwise taken from `metadata.clientId`, or from the entity id for client entries). Writing is best effort: a failure is logged and never undoes the business operation.
- What gets logged: client create/update/activate/deactivate, contact create/update/primary/deactivate, portfolio add/remove, visit start/result/reschedule/not visited/commercial outcome/attachments, follow-up scheduled/completed, quote status changes and order creation.
- `GET /clients/:id/history?page&limit` returns the entries newest first with the user's name.

### HU-16 — Portfolios

- Table `client_portfolios`: `client_id`, `portfolio_id`, `registered_at`, unique per pair.
- `GET /clients/:clientId/portfolios`, `POST /clients/:clientId/portfolios` `{ portfolioId }` (404 if the portfolio doesn't exist or is inactive, 409 if already associated), `DELETE /clients/:clientId/portfolios/:portfolioId`.
