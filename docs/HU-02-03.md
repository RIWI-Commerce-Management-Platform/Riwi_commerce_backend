## What was implemented

### 1. TLS to the database

Amazon RDS for PostgreSQL 15+ rejects unencrypted connections (`rds.force_ssl=1`). `src/shared/config/database-ssl.ts` builds the TLS options once and the three connections use them: the runtime TypeORM connection (`configuration.ts` → `app.module.ts`), the TypeORM CLI (`data-source.ts`) and Better Auth's `pg` Pool (`auth.ts`).

- `POSTGRES_SSL=true` turns TLS on; anything else (local docker compose) leaves it off.
- `POSTGRES_SSL_CA` points to the RDS CA bundle. The certificate is always verified (`rejectUnauthorized: true`); a missing bundle stops the app at startup.

### 2. `deploy.sh`

Run by Jenkins from the repo folder on the EC2. `DEPLOY_BRANCH` (default `main`) and `PM2_APP_NAME` (default `commerce-api`) can be overridden.

1. Checks that `.env` exists.
2. `git pull --ff-only` of the branch.
3. `npm ci` and `npm run build`.
4. `npm run migration:run` (against RDS, from the EC2).
5. `pm2 reload` if the app is already running, otherwise `pm2 start dist/main.js --node-args="--env-file=.env"`; then `pm2 save`.

### 3. Server `.env` (production)

```
POSTGRES_HOST=<RDS endpoint>.rds.amazonaws.com
POSTGRES_PORT=5432
POSTGRES_SSL=true
POSTGRES_SSL_CA=certs/rds-global-bundle.pem
```

Download the bundle once on the server:

```bash
mkdir -p certs && curl -o certs/rds-global-bundle.pem https://truststore.pki.rds.amazonaws.com/global/global-bundle.pem
```

Also set real values for `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `FRONTEND_URL` (https), `POSTGRES_PASSWORD`, the AWS variables and `AWS_SES_FROM_EMAIL`. With an IAM role on the EC2, leave `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` empty (the `.env.example` placeholders would be used as real keys). Leave `DEMO_PASSWORD` empty and don't run `seed:demo` in production.

### 4. Local development is unchanged

Docker compose keeps `POSTGRES_HOST=db` and `POSTGRES_SSL=false`. The `Dockerfile` (still `start:dev`) is only for local development. `.dockerignore` now keeps `.env`, `node_modules`, `dist`, `coverage`, `certs` and `.git` out of the image. No endpoint changed.
