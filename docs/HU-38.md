# HU-38 — Export reports to CSV

**Owner:** Valentina · **Epic:** E7 — Reports, indicators and QA · **Priority:** Alta
**Source:** `docs/Comercial360_Historias_y_Reparto_v2.pdf`

> As a director, I want to export reports to CSV.

## Acceptance criteria

| Criterion | Status |
|---|---|
| Exports visits, clients, quotes and orders | ✅ Done |
| With the active filters | ✅ Done |
| Opens correctly in Excel (UTF-8 with BOM) | ✅ Done |

## What was implemented

New module `src/modules/reports/` (registered in `AppModule`), read-only.

| Endpoint | Filters |
|---|---|
| `GET /reports/visits.csv` | `startDate`, `endDate` (scheduled date), `advisorId`, `clientId`, `zoneId`, `status` |
| `GET /reports/clients.csv` | `search`, `zoneId`, `clientTypeId`, `potentialId`, `municipality`, `isActive` |
| `GET /reports/quotes.csv` | `startDate`, `endDate` (creation), `advisorId`, `clientId`, `zoneId`, `status` |
| `GET /reports/orders.csv` | same as quotes |

- Admins and regional directors only; a director always exports their own zone.
- `application/csv.ts` writes RFC 4180 CSV with a UTF-8 BOM and CRLF line endings, quotes cells with separators/quotes/newlines, and prefixes cells starting with `=`, `+`, `-`, `@` so Excel doesn't run them as formulas.
- `?separator=semicolon` uses `;`, which Excel expects with a Spanish (Colombia) regional configuration; the default is `,`.
- The response is a download: `Content-Type: text/csv; charset=utf-8` and `Content-Disposition: attachment; filename="visits-2026-10-24.csv"`. At most 50,000 rows per export.
- `TypeOrmReportsDao` uses parameterized SQL (`src/shared/database/sql-conditions.ts`) over the other modules' tables, joining names (advisor, client, zone, catalogs, visit results).

## Tests

`application/export-report.use-case.spec.ts`, `shared/database/sql-conditions.spec.ts`. The four exports were also checked against a local database loaded with the demo seed.
