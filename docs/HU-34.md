# HU-34 — Listar cotizaciones y pedidos con filtros y paginación

**Owner:** Carlos · **Epic:** E5 — Cotizaciones, pedidos y archivos S3 · **Priority:** Media  
**Source:** `docs/Comercial360_Historias_y_Reparto_v2.pdf`  
**Status:** Próxima a implementar

> Como asesor o director comercial, quiero listar cotizaciones y pedidos con filtros, para consultar el historial comercial y dar seguimiento ágil a los clientes.

---

## Criterios de Aceptación

| Criterio | Estado | Especificación Técnica |
|---|:---:|---|
| Listado paginado de cotizaciones | ⏳ Pendiente | Endpoint `GET /quotes` con metadata (`page`, `limit`, `total`, `totalPages`) |
| Listado paginado de pedidos | ⏳ Pendiente | Endpoint `GET /orders` con metadata estandarizada |
| Filtro por cliente (`clientId`) | ⏳ Pendiente | Consulta exacta por ID de cliente |
| Filtro por asesor (`advisorId`) | ⏳ Pendiente | Permite filtrar ventas por asesor o director comercial |
| Filtro por estado | ⏳ Pendiente | Filtro por `QuoteStatus` (`DRAFT`, `SENT`, `APPROVED`, `REJECTED`) o `OrderStatus` |
| Filtro por rango de fechas | ⏳ Pendiente | Parámetros `startDate` y `endDate` aplicados sobre `created_at` |
| Ordenamiento estándar | ⏳ Pendiente | `ORDER BY created_at DESC` para priorizar transacciones recientes |
| Modelo de paginación transversal | ⏳ Pendiente | Reutilización de `src/shared/pagination/` (`PaginationQueryDto`, `PaginatedResult<T>`) |

---

## Especificación de Endpoints

### 1. `GET /quotes`
**Parámetros de consulta (Query params):**
- `page`: número de página (opcional, default `1`).
- `limit`: registros por página (opcional, default `10`, máx `100`).
- `clientId`: ID numérico del cliente (opcional).
- `status`: estado de la cotización (`DRAFT`, `SENT`, `APPROVED`, `REJECTED`).
- `startDate`: fecha inicio en formato `YYYY-MM-DD` (opcional).
- `endDate`: fecha fin en formato `YYYY-MM-DD` (opcional).

**Estructura de Respuesta (JSON):**
```json
{
  "data": [
    {
      "id": 1,
      "quoteNumber": "COT-0001",
      "clientId": 10,
      "status": "APPROVED",
      "subtotal": 150000.00,
      "total": 150000.00,
      "documentKey": "quotes/173000-doc.pdf",
      "createdAt": "2026-10-22T10:00:00.000Z"
    }
  ],
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 1,
    "totalPages": 1
  }
}
```

---

### 2. `GET /orders`
**Parámetros de consulta (Query params):**
- `page`: número de página (opcional, default `1`).
- `limit`: registros por página (opcional, default `10`, máx `100`).
- `clientId`: ID del cliente (opcional).
- `status`: estado del pedido (`CREATED`, `DISPATCHED`, `DELIVERED`, `CANCELLED`).
- `startDate`: fecha inicio `YYYY-MM-DD` (opcional).
- `endDate`: fecha fin `YYYY-MM-DD` (opcional).

**Estructura de Respuesta (JSON):**
```json
{
  "data": [
    {
      "id": 1,
      "orderNumber": "PED-0001",
      "quoteId": 1,
      "clientId": 10,
      "status": "CREATED",
      "subtotal": 150000.00,
      "total": 150000.00,
      "createdAt": "2026-10-22T10:30:00.000Z"
    }
  ],
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 1,
    "totalPages": 1
  }
}
```
