# HU-34 — Listar cotizaciones y pedidos con filtros y paginación

**Owner:** Carlos · **Epic:** E5 — Cotizaciones, pedidos y archivos S3 · **Priority:** Media<br>
**Source:** `docs/Comercial360_Historias_y_Reparto_v2.pdf`<br>
**Status:** ✅ **Completada**<br>
**Branch:** `feature-HU-33-34`

> Como asesor o director comercial, quiero listar cotizaciones y pedidos con filtros, para consultar el historial comercial y dar seguimiento ágil a los clientes.

---

## Criterios de Aceptación

| Criterio | Estado | Especificación Técnica & Implementación |
|---|:---:|---|
| Listado paginado de cotizaciones | ✅ Cumplido | Endpoint `GET /quotes` con metadata (`page`, `limit`, `total`, `totalPages`, `hasNextPage`, `hasPreviousPage`). |
| Listado paginado de pedidos | ✅ Cumplido | Endpoint `GET /orders` con metadata estandarizada. |
| Filtro por cliente (`clientId`) | ✅ Cumplido | Filtro opcional por ID de cliente en cotizaciones y pedidos. |
| Filtro por estado (`status`) | ✅ Cumplido | Filtro por `QuoteStatus` (`DRAFT`, `SENT`, `APPROVED`, `REJECTED`) y `OrderStatus` (`CREATED`, `DISPATCHED`, `DELIVERED`, `CANCELLED`). |
| Filtro por rango de fechas | ✅ Cumplido | Parámetros `startDate` y `endDate` aplicados sobre `created_at` (con fin de día 23:59:59.999). |
| Ordenamiento estándar | ✅ Cumplido | `ORDER BY created_at DESC` para priorizar transacciones recientes. |
| Modelo de paginación transversal | ✅ Cumplido | Reutilización de `src/shared/pagination/` (`PaginationQueryDto`, `PaginatedResult<T>`, `PaginatedResponseDto<T>`). |

---

## Especificación de Endpoints

### 1. `GET /quotes`
**Parámetros de consulta (Query params):**
- `page`: número de página (opcional, default `1`).
- `limit`: registros por página (opcional, default `10`, máx `100`).
- `clientId`: ID numérico del cliente (opcional).
- `status`: estado de la cotización (`DRAFT`, `SENT`, `APPROVED`, `REJECTED`).
- `startDate`: fecha inicio en formato `YYYY-MM-DD` (opcional).
- `endDate`: fecha fin en formato `YYYY-MM-DD` (opcional).

**Estructura de Respuesta (JSON):**
```json
{
  "data": [
    {
      "id": 1,
      "quoteNumber": "COT-0001",
      "clientId": 10,
      "status": "APPROVED",
      "subtotal": 150000.00,
      "total": 150000.00,
      "documentKey": "quotes/173000-doc.pdf",
      "documentUrl": "https://s3.amazonaws.com/...",
      "createdAt": "2026-10-22T10:00:00.000Z",
      "updatedAt": "2026-10-22T10:00:00.000Z"
    }
  ],
  "meta": {
    "total": 1,
    "page": 1,
    "limit": 10,
    "totalPages": 1,
    "hasNextPage": false,
    "hasPreviousPage": false
  }
}
```

### 2. `GET /orders`
**Parámetros de consulta (Query params):**
- `page`: número de página (opcional, default `1`).
- `limit`: registros por página (opcional, default `10`, máx `100`).
- `clientId`: ID del cliente (opcional).
- `status`: estado del pedido (`CREATED`, `DISPATCHED`, `DELIVERED`, `CANCELLED`).
- `startDate`: fecha inicio `YYYY-MM-DD` (opcional).
- `endDate`: fecha fin `YYYY-MM-DD` (opcional).

**Estructura de Respuesta (JSON):**
```json
{
  "data": [
    {
      "id": 1,
      "orderNumber": "PED-0001",
      "quoteId": 10,
      "clientId": 5,
      "status": "CREATED",
      "subtotal": 150000.00,
      "total": 150000.00,
      "items": [],
      "createdAt": "2026-10-23T10:30:00.000Z",
      "updatedAt": "2026-10-23T10:30:00.000Z"
    }
  ],
  "meta": {
    "total": 1,
    "page": 1,
    "limit": 10,
    "totalPages": 1,
    "hasNextPage": false,
    "hasPreviousPage": false
  }
}
```
