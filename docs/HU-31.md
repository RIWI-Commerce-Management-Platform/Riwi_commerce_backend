## Detalles de Implementación (Arquitectura Limpia)

### 1. Capa de Dominio (`src/modules/quotes/domain/`)
- **Entidad `Quote`:**
  - Atributo inmutable/mutable `documentKey: string | null`.
  - Método de dominio `attachDocument(key: string): void`: actualiza la clave S3 y renueva `updatedAt = new Date()`.
- **Excepciones de dominio:**
  - `QuoteNotFoundError`: lanzada si el ID de cotización no existe en la base de datos.

### 2. Capa de Aplicación (`src/modules/quotes/application/`)
- **Caso de Uso `AttachQuoteDocumentUseCase`:**
  - Recibe `{ quoteId, fileBuffer, filename, mimetype }`.
  - Verifica la existencia de la cotización vía `QuoteRepository.findById()`.
  - Delega la subida a AWS S3 mediante el puerto compartido `FileStorageService.upload({ buffer, filename, mimetype, folder: 'quotes' })`.
  - Asigna la clave S3 resultante a la cotización con `quote.attachDocument(uploaded.key)` y persiste con `QuoteRepository.save(quote)`.
  - Genera una URL prefirmada temporal con `FileStorageService.getPresignedUrl(uploaded.key)` y retorna `{ quote, documentUrl }`.
- **Actualización de `GetQuoteByIdUseCase`:**
  - Si la cotización encontrada contiene `documentKey`, invoca `FileStorageService.getPresignedUrl()` y adjunta la URL temporal firmada en la respuesta.

### 3. Capa de Infraestructura (`src/modules/quotes/infrastructure/`)
- **Entidad TypeORM `QuoteOrmEntity`:**
  - Mapeo de columna `@Column({ name: 'document_key', type: 'varchar', length: 500, nullable: true })`.
- **Mapper `QuoteMapper`:**
  - Mapeo bidireccional entre `documentKey` de dominio y `document_key` de persistencia.

### 4. Capa de Presentación (`src/modules/quotes/presentation/`)
- **Endpoint `POST /quotes/:id/attachment`:**
  - Anotado con `@ApiConsumes('multipart/form-data')` y decorador `@UseInterceptors(FileInterceptor('file'))`.
  - Valida la presencia del archivo subido (HTTP 400 si falta el archivo).
  - Retorna `QuoteResponseDto` enriquecido con `documentUrl` y `documentKey`.
