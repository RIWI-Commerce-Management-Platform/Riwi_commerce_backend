## HU-31: Attach Commercial Support Document/Image to Quote

> As an advisor, I want to attach a commercial support file (PDF or image) to a quote and store it in Amazon S3, so the client and team can view or download it via a secure signed URL.

### Acceptance Criteria
- [x] Endpoint `POST /quotes/:id/attachment` using multipart/form-data.
- [x] File validation: allowed MIME types (PDF, PNG, JPEG, WebP) and maximum size (10MB).
- [x] File upload to AWS S3 using the shared `FileStorageService` under the `quotes/` folder.
- [x] `documentKey` persisted in the `quotes` table.
- [x] Temporary presigned URL (`documentUrl`) generated and returned for immediate viewing/downloading.
- [x] `GET /quotes/:id` automatically resolves presigned `documentUrl` when `documentKey` exists.
- [x] Returns 404 if quote does not exist (`QuoteNotFoundError`).
- [x] Swagger documentation with binary file upload schema.

## HU-32: Quote State Transition Lifecycle with Activity Log

> As an advisor, I want to transition a quote through its status lifecycle (Draft -> Sent -> Approved / Rejected), with every change audited in the transversal activity log.

### Acceptance Criteria
- [x] Domain-driven state transitions:
  - `DRAFT` $\rightarrow$ `SENT`, `REJECTED`
  - `SENT` $\rightarrow$ `APPROVED`, `REJECTED`
  - `APPROVED` and `REJECTED` are terminal statuses.
- [x] Domain validation: throws `InvalidQuoteStatusTransitionError` (HTTP 400) on illegal transitions.
- [x] Endpoint `PATCH /quotes/:id/status` accepting `{ status: QuoteStatus }`.
- [x] Every status transition is recorded in `ActivityLogService`:
  - `action`: `quote.status_changed`
  - `entityType`: `quote`
  - `entityId`: quote ID
  - `actorId`: extracted from request or default
  - `metadata`: `{ clientId, quoteNumber, previousStatus, newStatus }`
- [x] Returns updated `QuoteResponseDto`.
- [x] Fully covered by unit tests (domain, application use case, presentation controller).
