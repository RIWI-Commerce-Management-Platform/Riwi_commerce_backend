## What was implemented

Migration `visit/.../1792720000400-AddVisitFollowUpsAttachmentsAndOutcome.ts`.

### HU-25 — Follow-ups

- Table `follow_ups`: `visit_id`, `client_id`, `responsible_id`, `created_by`, `due_date`, `activity` (≤150), `observation` (≤500), `status` (`PENDING`/`COMPLETED`), `completed_at`.
- `POST /visits/:id/follow-ups` `{ dueDate, activity, observation?, responsibleId? }`: the visit must belong to the advisor; the responsible defaults to them.
- `GET /follow-ups/agenda?period=day|week&date&status`: the follow-ups the user is responsible for, with the client name, so the agenda shows them next to `GET /visits/agenda`. Both use the same day/week range (`application/use-cases/agenda-range.ts`).
- `PATCH /follow-ups/:id/complete`: by the responsible or the creator; completing twice is a 400.

### HU-26 — Reschedule / not visited

- `PATCH /visits/:id/reschedule` `{ scheduledAt, reason? }`: from `PENDING` or `RESCHEDULE`, to a future date only; status becomes `RESCHEDULE`. A rescheduled visit can still be started.
- `PATCH /visits/:id/not-visited` `{ reason? }`: from `PENDING`, `RESCHEDULE` or `IN_PROGRESS`; status becomes `NOT_VISITED`.
- Both write to the activity log with the previous and new date / reason.

### HU-27 — Commercial outcome

- `visits` got `quote_generated` and `order_generated`, returned in the visit detail.
- `PATCH /visits/:id/commercial-outcome` `{ quoteGenerated, orderGenerated }` (visit in progress or done).
- `POST /quotes` accepts `visitId`, stored in `quotes.visit_id`. When the advisor answers "yes", the frontend opens the quote form with `clientId` and `visitId` of the visit.

### HU-28 — Attachments

- Table `visit_attachments`: `visit_id`, `file_key`, `original_name`, `mime_type`, `size`, `uploaded_by`. The file is in S3 under `visits/<id>/`; the database keeps only the key.
- `POST /visits/:id/attachments` (multipart `file`, same limits as HU-29: 10 MB, PDF/images/CSV/Excel), `GET /visits/:id/attachments` (signed URL per file and `isImage` so the frontend shows a thumbnail or a link), `DELETE /visits/:id/attachments/:attachmentId`.
